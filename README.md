# CodeClip

Local-first code snippet desk for developers. Create, tag, search, copy, and export snippets — data stays in your browser on **127.0.0.1**.

## Features

- Create / edit / delete snippets
- Tags + full-text search
- Language filter
- Copy to clipboard
- JSON import / export
- Seeded demo snippet on first load

## Setup

```bash
npm install
npm test
npm run build
npm start   # http://127.0.0.1:8787/
```

## Stop

Ctrl+C

## Privacy

No accounts. Persistence is `localStorage` only. Export is opt-in.

## Self-adaptation

This app continuously learns from a **representative** public-web scan on the Mac Studio (not the entire internet).

**Latest:** Enhance CodeClip with AI-Powered Snippet Organization

By integrating machine learning algorithms, CodeClip can automatically categorize and suggest relevant tags for code snippets, improving user experience and efficiency. Additionally, incorporating real-time collaboration features will allow developers to share and discuss snippets more effectively.

See `learning/LATEST.json` and `public/insights.json`.
